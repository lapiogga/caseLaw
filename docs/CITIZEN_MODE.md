# CITIZEN_MODE — 일반인 사전진단 사용 가이드

> v0.4.0 (Phase 7 MVP). 변호사 상담 전 단계의 일반 시민용.

## 누구를 위한 것?

법률 분쟁을 겪고 있지만 **변호사 상담 전 단계**의 일반 시민:

- "내가 이걸로 소송할 수 있나?"
- "이게 민사야 형사야?"
- "변호사 꼭 써야 해?"
- "비용은 얼마? 시간은?"
- "지금 시작해도 늦지 않은가?"

## 빠른 시작

### 1. 모드 전환

채팅창에서:

```
caselaw로 일반인 모드로 바꿔줘
```

또는 직접:

```
set_user_mode 도구를 citizen으로 호출
```

확인:

```
지금 모드 뭐야?
→ get_user_mode()
→ {"mode": "citizen", "source": "file"}
```

### 2. 사실관계 입력 (자유 형식)

```
3년 전 친구한테 5천만 원 빌려줬는데 안 갚고 있어요. 차용증은 카톡으로만 있어요.
사건 발생일은 2022-03-15입니다.
```

내부적으로 `triage_dispute(situation="...", event_date="2022-03-15")` 자동 호출.

## 자동 안내되는 정보 (각 카테고리당)

- ✅ 적용 가능 법률 조문
- ✅ 소멸시효 (event_date 입력 시 자동 점검)
- ✅ 일반적 절차 흐름
- ✅ 셀프 소송 가능 여부 (소액사건심판 한도 3,000만 원)
- ✅ 권장 증거 목록
- ✅ 흔한 쟁점
- ✅ 무료/긴급 상담처 (해당 시)
- ✅ 면책 고지 (자동 부착)

## 면책 고지 6종 (상황별 자동 부착)

| 종류 | 부착 조건 |
|---|---|
| `standard` | 항상 |
| `ai_limitation` | 항상 |
| `statute_imminent` | 시효 임박/만료 |
| `criminal_serious` | 형사 사건 매칭 |
| `victim_support_needed` | 피해자 지원 필요 시 (Phase 8+) |
| `data_freshness` | 법령 개정 가능성 안내 (Phase 8+) |

## 자연어 시나리오 예시

### 대여금
> *"4년 전 친구한테 천만원 빌려줬는데 안 갚아요. 카톡으로 빌렸다는 메시지는 있어요."*

→ civil.loan, 시효 안전, 소액사건심판 가능

### 임대차 보증금
> *"전세 만료됐는데 집주인이 보증금 안 돌려줘요"*

→ civil.deposit, 임차권등기명령 + 보증금반환청구

### 임금체불
> *"회사가 6개월 임금 안 줘서 퇴사했는데 어떡하죠"*

→ labor.unpaid_wage, 시효 3년, 고용노동부 1350

### 음주운전
> *"음주운전 단속됐어요"*

→ criminal.dui, 형사 면책 자동 부착

### 시효 임박 케이스
> *"5년 전에 의료사고 당했는데 지금이라도 가능?"* (event_date=5년 전)

→ civil.medical, 시효 임박/만료 경고 + 즉시 변호사 상담 권장

## 변호사·로펌 모드와의 차이

| 항목 | citizen | lawyer (v0.3.0 기본) |
|---|---|---|
| 입력 | 자유 형식 사실관계 | 사건번호, 법령명 |
| 출력 | 일상어 안내 + 다음 단계 | 판례 본문, 법조문 원문 |
| 면책 | 매 응답 자동 부착 | 미부착 |
| 무료자원 | 자동 추천 | 미언급 |
| 의도 분류 | LLM + 키워드 매칭 | 사용자가 선택 |

## 한계 (정직)

1. **카테고리 30종**은 1차 자체 작성. 변호사 검토 전.
2. **키워드 매칭** 기반 → 호스트 LLM의 자연어 이해 품질이 중요. Claude·GPT 같은 강력한 LLM과 함께 사용 권장.
3. **법령 자동 갱신 없음** → 법 개정 시 categories.json 수동 갱신 필요.
4. **법률 자문 아님** — 모든 응답이 면책으로 명시. 진짜 의사결정은 변호사 상담.

## 권장 워크플로 (일반인)

```
1. set_user_mode("citizen")
2. triage_dispute(사실관계, event_date)
3. 응답에서 "next_steps" 와 "candidates[0]" 우선 검토
4. 시효 임박이면 즉시 변호사 상담
5. 셀프 소송 가능이면 소액사건심판 (대법원 전자소송 https://ecfs.scourt.go.kr)
6. 변호사 상담 가면 응답 결과를 그대로 가져가서 보여주기
```

## 향후 추가 예정 (Phase 8+)

- `check_statute_of_limitations` (시효 중단·정지 포함 정밀 점검)
- `estimate_litigation_cost` (인지대·송달료·변호사비)
- `interview_facts` (다턴 사실관계 인터뷰)
- `evaluate_case_strength` (유사 판례 통계)
- `recommend_pro_bono` (지역·분쟁별 무료 상담처)
- `prepare_consultation_kit` (변호사 상담 준비 PDF 자동 생성)
