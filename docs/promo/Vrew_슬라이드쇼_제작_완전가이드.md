# Vrew 슬라이드쇼 영상 제작 — 처음 사용자 완전 가이드

> 화면 녹화 없이, 이미 만든 캡처 11장 + AI 음성으로 약 3분짜리 영상을 만듭니다.
> Vrew 설치부터 YouTube 업로드까지 모든 클릭을 시간 순서대로 안내합니다.
>
> **총 소요 시간**: 1-1.5시간 (Vrew 설치 10분 + 영상 제작 50분 + 업로드 10분)
> **준비물**: 본 레포의 `docs/promo/images/` 11장 이미지 (이미 준비 완료)
> **결과물**: 1080p MP4, 약 3분, YouTube 업로드 가능

---

## 0단계 — Vrew 설치 (5-10분, 한 번만)

### 0-1. 다운로드

브라우저로 <https://vrew.voyagerx.com> 접속.

화면 중앙 큰 버튼 **"무료로 시작"** 또는 **"Windows용 다운로드"** 클릭.

`Vrew-Setup-x.x.x.exe` 파일 (약 200MB) 다운로드.

### 0-2. 설치

다운로드한 EXE 파일 더블클릭 → 다음 → 다음 → 설치 → 완료. 5분 정도 소요.

### 0-3. 회원가입

설치 완료 후 Vrew 자동 실행 → '회원가입' 또는 'Google로 시작' 선택 (네이버·카카오·구글 OAuth 가능).

가입 후 자동 로그인. 무료 플랜으로 시작 — **월 10,000자 AI 음성 + 자동 자막 120분** 무료 (본 영상 1개에 충분).

## 1단계 — 새 프로젝트 만들기 (2분)

### 1-1. 첫 화면

Vrew 열면 좌상단에 **'새로 만들기'** 버튼이 있습니다. 클릭.

### 1-2. 프로젝트 유형 선택

화면에 4-5개 옵션이 나옵니다:
- 동영상에서 자막 만들기
- 이미지·동영상으로 영상 만들기 ← **이걸 선택**
- AI 목소리로 영상 만들기
- 직접 더빙하기

**"이미지·동영상으로 영상 만들기"** 또는 **"빈 프로젝트로 시작"** 선택.

### 1-3. 화면 비율 설정

**16:9 가로형 (1920x1080)** 선택. YouTube 표준.

> 모바일 (TikTok·Reels) 도 동시 만들고 싶다면 나중에 9:16 세로형 별도 프로젝트로 변환 가능.

### 1-4. 프로젝트 이름

`CaseLaw-MCP-홍보-3분` 같은 이름으로 저장.

### 4-2. AI 음성 적용

13개 자막을 모두 입력한 후, 상단 메뉴에서:

1. **'AI 목소리'** 또는 **'전체 더빙'** 클릭
2. 음성 종류 선택 — **'경준'** (남성, 차분, 추천) 또는 **'한나'** (여성, 명료)
3. 속도: **1.0배** (기본). 너무 느리면 1.05배.
4. 톤: 기본
5. **'전체 적용'** 클릭

30초-1분 정도 후 모든 클립에 AI 음성이 자동 입혀집니다.

### 4-3. 미리듣기 + 어색한 부분 수정

각 클립을 재생해 음성 들어보고, 어색한 부분 수정:

| 자주 어색한 부분 | 수정 방법 |
|---|---|
| 영문 약자 발음 이상 | 한글로 풀어쓰기 (이미 위에 적용됨) |
| 숫자 발음 이상 | "0.8.0" → "영점팔점영" 또는 "공점팔점공" |
| 빠르게 들림 | 속도 0.95배 |
| 어조가 단조로움 | 다른 음성 시도 (도선, 진우 등) |

## 5단계 — 자막 디자인 (10분)

### 5-1. 자막 자동 생성

상단 메뉴 **'자막'** → **'자동 자막 생성'** 클릭. AI 음성 기반으로 자동 생성되어 정확도 거의 100%.

### 5-2. 자막 스타일 변경

자막 클릭 → 우측 패널에서:

| 항목 | 권장 값 |
|---|---|
| 글꼴 | '나눔스퀘어' 또는 '본명조' (가독성) |
| 글꼴 크기 | 36-44pt (모바일 배려) |
| 글꼴 색 | 흰색 |
| 외곽선 | 검은색 3pt (어떤 배경에서도 보임) |
| 위치 | 화면 하단 중앙 |
| 배경 박스 | 반투명 검은색 (선택) |

### 5-3. 강조할 단어에 색상

핵심 단어만 색 변경 (선택):
- "5분 안에" → 노란색
- "오씨 키" → 노란색
- "자동" → 초록색
- "100퍼센트 성공" → 초록색

자막 텍스트 일부만 드래그 → 글자 색 변경.

## 6단계 — BGM 추가 (선택, 5분)

### 6-1. BGM 라이브러리

Vrew 좌측 메뉴 **'음악'** 또는 **'배경음'** 선택.

추천 분위기: **'잔잔한', '카페', '부드러운', '일렉트로닉 잔잔'**

검색어 예: `lo-fi`, `cafe`, `gentle`

### 6-2. BGM 추가 + 음량 조정

마음에 드는 곡 우클릭 → '전체 영상에 추가'.

음량: **-25dB ~ -30dB** (음성보다 훨씬 작게)

> BGM이 음성보다 크면 무조건 산만함. 들릴락 말락 하는 정도가 적정.

### 10-3. 썸네일 (5분)

YouTube 자동 생성 3개 중 선택하거나, 직접 제작.

직접 제작 시 — Canva 무료 템플릿 사용:
1. <https://canva.com> → "YouTube 썸네일" 검색
2. 템플릿 선택 후 텍스트 변경:
   - 큰 글씨 (왼쪽): **"5분 만에 끝"**
   - 작은 글씨 (오른쪽): **"한국 판례 AI 검색"** + GitHub 로고
   - 배경: 본 영상의 capture-02 (ping 응답) 스크린샷
3. PNG 다운로드 → YouTube 썸네일에 업로드

### 10-4. 게시

**'게시'** 클릭 → 영상 URL 복사.

YouTube URL은 보통 `https://www.youtube.com/watch?v=XXXXXXXXXXX` 형태. 마지막 11자리가 비디오 ID.

## 트러블슈팅

### Vrew가 너무 무거움·느림

- 영상 가져올 때 GIF는 한 번에 변환됨. 시간 걸림 (1분 정도).
- 노트북이 사양 낮으면 720p로 내보내기 (1080p 대신).

### AI 음성 글자 수 초과

- 무료 플랜 월 10,000자. 본 영상 음성 합쳐서 약 600자 → 충분.
- 초과 시 다음 달까지 기다리거나 유료 전환.

### "0.8.0" 발음이 이상함

자막에서 `0.8.0` → `영 점 팔 점 영` 또는 `공 점 팔 점 공` 으로 바꿔서 다시 더빙.

### 자동 자막에 한자가 섞임

자막을 직접 편집해 한글로만 변경.

### 영상 용량이 너무 큼 (200MB 이상)

내보내기 옵션에서 비트레이트를 3000kbps로 낮춤. 100MB 이하로 떨어집니다.

## 다국어 영상 (보너스, 시간 있을 때)

본 도구가 5개 언어를 지원하므로, 같은 영상을 영어/중국어로 만들면 글로벌 노출 가능.

### 영어 버전 만들기 (30분)

1. 본 프로젝트 복사 → "CaseLaw-MCP-Promo-EN-3min" 으로 이름 변경
2. 각 클립의 자막을 영어로 번역 (Vrew '번역' Beta 기능 또는 직접):

```
[클립 1] Korean Supreme Court precedents, statutes, and constitutional decisions
— search them all in your AI chat. Here's how to set it up in 5 minutes.

[클립 2] First, get your free OC key from Korea's bopjecheo OPEN API site
at open.law.go.kr.

...
```

3. AI 음성을 영어로 변경 (Vrew의 영어 음성 'Brian', 'Emily' 등)
4. 자막 자동 재생성
5. 별도 MP4로 내보내기

### YouTube에 영어 영상 별도 업로드

같은 채널에 별도 영상으로 업로드. 제목 영어:
```
Search Korean Law in Your AI Chat — Free Setup in 5 Minutes (CaseLaw MCP)
```
