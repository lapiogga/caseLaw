# Vrew 로 5분 영상 만들기 — 단계별 가이드

> **목표**: 화면 녹화 + 자동 자막 + AI 음성 더빙 까지 한 번에. 본인 음성 녹음 없이도 완성된 한국어 영상이 나옵니다.
>
> **소요 시간**: 1-2시간 (Vrew 익숙하면 30분)
>
> **결과물**: YouTube 또는 Loom 업로드 가능한 1080p MP4

---

## Vrew 란?

네이버 자회사 보이저엑스(VoyagerX)가 만든 **AI 영상 편집 도구**. 한국어 특화로:

- 화면 녹화 영상에서 **음성 → 자동 자막 변환** (정확도 95%+)
- 텍스트만 입력하면 **AI 음성으로 더빙** (남/여, 다양한 톤)
- 컷 편집, 자막 디자인, BGM 삽입 모두 GUI
- **무료 플랜**: 월 영상 30분, AI 음성 1만 자, 자동 자막 120분 (5분 영상에 충분)

다운로드: <https://vrew.voyagerx.com>

---

## 두 가지 제작 방식 비교

### 방식 A — 본인 화면 녹화 + 자동 자막만 (가장 빠름)

본인 음성 녹음 → Vrew 가 자막 자동 생성. 영상 인간미 있음. 30분이면 완성.

### 방식 B — 화면 녹화 + 텍스트 → AI 음성 + 자동 자막 (얼굴·음성 노출 X)

화면만 녹화하고 음성은 AI 가 읽음. 완전 익명, 다국어로 쉽게 변환 가능. 1-2시간.

---

# 방식 B 추천 — 단계별 (1-2시간)

## 0단계: 준비물

- [ ] 노트북 또는 데스크톱 (Windows/Mac)
- [ ] 본 레포의 `docs/promo/영상_대본_5분.md` (각 컷의 음성 텍스트가 정리되어 있음)
- [ ] 화면 녹화 도구: **Vrew 자체 화면 녹화** 기능 사용 가능. 또는 OBS Studio.
- [ ] Vrew 무료 회원가입: <https://vrew.voyagerx.com> → '시작하기'

---

## 1단계: 화면 녹화 (30-40분)

### 1-1. Vrew 또는 OBS 로 화면 녹화

`docs/promo/영상_대본_5분.md` 의 [화면 안내] 칸을 참고하면서 30개 컷의 화면을 녹화합니다.

**녹화 팁**:
- **음성 없이 화면만** 녹화 (음성은 4단계에서 AI 가 추가)
- 컷 사이는 1-2초 여백 주기 (편집하기 편함)
- 마우스 강조: ScreenToGif 의 'Mouse Highlighter' 또는 OBS 의 'Mouse Highlighter' 플러그인
- 개인정보(OC 키, 이메일) 는 미리 모자이크된 가짜 데이터로 입력하거나, 후편집에서 가림

**녹화 순서 권장**:
1. **00:20-01:30 (OC 키 발급)** — 실제 회원가입 안 하고 이미 가입된 계정으로 녹화
2. **01:30-02:30 (다운로드)** — 새로 다운로드해서 녹화
3. **02:30-04:00 (자동 설치)** — 설치 스크립트 실제 실행 녹화 (가장 긴 컷)
4. **04:00-05:00 (사용 예시)** — Claude Desktop 에서 실제 명령 실행

각 컷을 별도 파일로 저장하지 말고 **하나의 긴 녹화** 로 한 번에 진행하면 편집이 쉽습니다.

### 1-2. 녹화 파일 저장

`raw_screen_recording.mp4` 같은 이름으로 저장. 30-40분 분량 (편집 후 5분으로 압축 예정).

---

## 2단계: Vrew 에 업로드 + 컷 편집 (20분)

### 2-1. Vrew 새 프로젝트

Vrew 실행 → '새로 만들기' → '동영상에서 자막 만들기' 또는 '직접 더빙하기' 선택.

**여기서는 '직접 더빙하기' 를 추천**: 음성을 텍스트로 바꿀 게 아니라, 텍스트 → AI 음성으로 갈 것이기 때문.

### 2-2. 화면 녹화 영상 가져오기

상단 메뉴에서 '동영상 가져오기' → 1단계 녹화 파일 선택.

Vrew 는 자동으로 **장면(scene) 단위로 컷을 나눕니다**. 30개 정도의 클립으로 분할됩니다.

### 2-3. 불필요한 부분 잘라내기

- 녹화 시 멈칫한 부분, 잘못 클릭한 부분, 너무 긴 대기 시간을 잘라냅니다.
- Vrew 의 '클립 자르기' 기능 (단축키: Ctrl+B)
- 목표: 5분 분량으로 압축

---

## 3단계: 자막 + AI 음성 입력 (40분)

### 3-1. 클립별 자막 입력

각 클립에 `docs/promo/영상_대본_5분.md` 의 [음성] 칸 텍스트를 그대로 붙여넣습니다.

| 컷 번호 | Vrew 클립 | 음성 텍스트 |
|---|---|---|
| #1 | 인트로 | "안녕하세요. 오늘은 대법원 판례..." |
| #2 | GitHub 페이지 | "변호사가 아니어도 사용 가능합니다..." |
| ... | ... | ... |

### 3-2. AI 음성 적용

각 자막을 입력한 후, 우측 패널에서:

1. **음성 종류 선택**:
   - 추천: '경준' (남성, 차분), '한나' (여성, 명료), '도선' (남성, 친근)
2. **속도**: 1.0x (기본) — 너무 빠르면 0.95x
3. **'전체 더빙'** 클릭 → 30초 정도 후 자동 음성 생성

미리듣기로 어색한 부분 확인.

### 3-3. 자동 자막 생성

상단 메뉴에서 '자막' → '자동 자막 생성' (AI 음성 기반 자동, 보통 100% 정확).

### 3-4. 자막 디자인

- **글꼴 크기**: 36-48pt (모바일에서도 잘 보이게)
- **글꼴 색**: 흰색 + 검은 외곽선 (어떤 배경에서도 가독성)
- **위치**: 화면 하단 중앙
- **배경**: 반투명 검은 박스 (선택)

## 4단계: 마무리 작업 (15분)

### 4-1. 인트로/아웃트로 추가

- **인트로 (3초)**: 영상 타이틀 "한국 판례·법령을 AI 채팅에서 5분 만에"
- **아웃트로 (5초)**: GitHub URL + "구독·좋아요 부탁드립니다"

Vrew 의 '템플릿' 메뉴에서 무료 템플릿 사용 가능.

### 4-2. BGM (선택)

- Vrew 무료 BGM 라이브러리에서 카페 또는 일렉트로닉 잔잔한 곡 선택
- 음량: -25dB (음성보다 훨씬 작게)

### 4-3. 컷 전환 효과

- 컷과 컷 사이에 0.3초 페이드 인/아웃
- 너무 화려한 전환은 피하기 (정보 전달이 목적)

## 트러블슈팅

### Vrew 가 음성을 제대로 인식 못함

방식 A 의 경우. 마이크 음량이 너무 작거나 BGM이 음성과 비슷한 음량일 때 발생. 마이크 음량 -12dB 이상, BGM은 -25dB 이하.

### AI 음성이 이상하게 발음

영어/한자/숫자가 섞이면 가끔 어색. 한글로 풀어쓰기:
- "PyPI" → "파이피아이" 또는 "파이썬 패키지 인덱스"
- "OC" → "오씨" 또는 "오 씨"
- "Ctrl+V" → "컨트롤 브이"

### 영상 용량이 너무 큼

Vrew 내보내기 옵션에서 '비트레이트' 를 5000kbps 로 낮춤. 5분 영상이 200MB 이하로 떨어집니다.

## 다국어 영상 만들기 (보너스)

본 도구가 5개 언어를 지원하므로, 같은 영상을 영어/중국어로도 만들면 글로벌 노출 가능.

**Vrew 다국어 워크플로**:

1. 한국어 영상 완성
2. Vrew 의 '번역' 기능 (Beta) 으로 자막 자동 번역 → 검수
3. 같은 화면에 영어 AI 음성 더빙 적용
4. 별도 영상으로 내보내기

**예상 추가 시간**: 언어당 30분 (자막 검수 위주)

타겟 시장:
- **영어**: 한국 거주 외국인 노동자, 결혼이민자
- **중국어**: 화교, 중국인 유학생
- **베트남어**: 베트남 결혼이민자, 노동자
