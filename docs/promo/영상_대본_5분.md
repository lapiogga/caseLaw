# 5분 홍보·설치 영상 대본 (음성·자막·화면 분리)

> **사용 방법**: 사용자(녹화자)는 본 대본을 읽으면서 [화면 안내] 대로 화면을 조작하고, [음성] 칸을 그대로 읽으면 됩니다. [자막]은 후편집(또는 Vrew 자동 자막)에서 화면 하단에 표시.

**총 길이**: 5분 0초 (5:00)
**포맷**: 1920x1080, 30fps, MP4
**음성**: 사용자 본인 또는 Vrew AI 음성 (한국어 여성/남성 명료체)
**BGM**: 권장 없음 (음성·자막에 집중) 또는 무저작권 카페 스타일 -20dB
**전제**: 사용자가 Windows 11, Claude Desktop 미설치 상태에서 시작
