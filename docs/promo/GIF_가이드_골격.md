# 시각자료 가이드 (GIF + 스크린샷 + 캡션)

> **목적**: 영상 대신 README에 직접 노출되는 단계별 시각 가이드. 영상보다 검색·인덱싱·번역에 유리하고 모바일에서도 잘 보임.
>
> **사용 방법**: 본 파일 골격을 그대로 두고, 각 `[GIF 자리]` 또는 `[스크린샷 자리]` 에 사용자가 캡처한 이미지를 채워 넣은 뒤 docs/ 또는 README 에서 링크하면 됩니다.

## 캡처에 필요한 무료 도구

| 도구 | 용도 | 다운로드 |
|---|---|---|
| **ScreenToGif** | 화면을 GIF 로 녹화. 5MB 이하 권장 | <https://www.screentogif.com> |
| **ShareX** | 정적 스크린샷 + 화살표·번호 주석 | <https://getsharex.com> |
| **Snipping Tool** | Windows 기본, 간단한 영역 캡처 | Windows + Shift + S |
| **Squoosh** | 이미지 용량 줄이기 (PNG → WebP) | <https://squoosh.app> |

---

## 캡처 가이드라인

- **해상도**: 1280x720 또는 1920x1080 (선명도 우선)
- **GIF 길이**: 단일 동작 5-10초 이내
- **GIF 용량**: 파일당 5MB 이하 (GitHub README 로딩 속도)
- **개인정보 가림**: OC 키, 이메일, 본인 이름은 모자이크 또는 `gild***` 같은 마스킹
- **프레임률**: 10fps (충분, 용량 절약)
- **마우스 커서**: 강조 효과 켜기 (ScreenToGif 옵션)

# 본문 (이대로 README 또는 docs/INSTALL_시각.md 에 복사)

> 본 가이드는 컴퓨터에 익숙하지 않은 분도 차근차근 따라할 수 있도록 만들어졌습니다.
> 클릭만 하시면 됩니다.

## 1단계: 법제처 OC 키 발급 (5분, 무료)

### 1-1. 사이트 접속

브라우저 주소창에 다음 주소를 입력하거나 [여기](https://open.law.go.kr/LSO/openApi/cuAskList.do)를 누르세요.

```
https://open.law.go.kr/LSO/openApi/cuAskList.do
```

[스크린샷 자리: open.law.go.kr 첫 화면, 우측 상단 '회원가입' 버튼에 빨간 동그라미]

### 1-2. 회원가입

우측 상단 '회원가입' 버튼을 누르고, 이메일·이름·비밀번호를 입력합니다.

[스크린샷 자리: 회원가입 양식, 이메일 ID 부분에 "이 부분이 OC 키가 됩니다" 캡션]

> **중요**: 이메일 ID 의 `@` 앞부분이 보통 OC 키가 됩니다.
> 예: `hong@naver.com` → OC 키는 `hong`

### 1-3. 이메일 인증

가입한 이메일 받은 편지함에서 인증 링크를 누릅니다.

[스크린샷 자리: 인증 메일 화면, 인증 버튼 강조]

### 1-4. 활용신청

로그인 후 상단 메뉴에서 '활용신청' 클릭.

[스크린샷 자리: 로그인 후 상단 메뉴, '활용신청' 메뉴에 화살표]

### 1-5. 신청 양식 작성

| 항목 | 입력값 |
|---|---|
| 활용 목적 | "AI 보조 도구" 또는 "개인 법률 정보 검색" |
| 활용 분야 | "기타" |
| 사용 기관 | 본인 이름 |
| 활용 API | **전체 선택** 권장 |

[스크린샷 자리: 활용신청 양식 작성 완료된 모습, '신청' 버튼 강조]

### 1-6. OC 키 확인

신청은 보통 즉시 자동 승인됩니다. **마이페이지 → API인증키관리** 에서 OC 키 확인.

[스크린샷 자리: 마이페이지의 OC 키 표시 화면, 키 부분에 "이걸 복사하세요" 캡션. 키는 `gild***` 처럼 마스킹]

복사 (Ctrl+C) 후 다음 단계로.

## 2단계: 설치 패키지 다운로드 (1분)

### 2-1. 다운로드

[설치 패키지 (7KB)](https://github.com/lapiogga/caseLaw/releases/download/v0.8.0/CaseLaw-installer-v0.8.0.zip) 를 누르면 `CaseLaw-installer-v0.8.0.zip` 파일이 다운로드됩니다.

[GIF 자리: 링크 클릭 → 브라우저 하단에 다운로드 표시 → 다운로드 폴더 열기까지 5초]

### 2-2. 압축 풀기

다운로드 폴더에서 ZIP 파일을 우클릭 → '압축 풀기' 또는 '여기에 압축 풀기'.

[GIF 자리: ZIP 우클릭 → '압축 풀기' 선택 → 압축 푼 폴더 안의 파일들이 보이는 모습 (8초)]

압축을 풀면 폴더 안에 다음 파일들이 보입니다:

```
CaseLaw-설치-v0.8.0/
├── 설치하기.bat              ← 다음 단계에서 더블클릭할 파일
├── setup-for-novice.ps1      (자동 실행됨)
├── 읽어주세요.txt
└── docs/
    └── OC발급_가이드.md
```

## 3단계: 자동 설치 (3-7분)

### 3-1. 설치하기.bat 더블클릭

`설치하기.bat` 를 더블클릭합니다.

[스크린샷 자리: 압축 푼 폴더 안에서 '설치하기.bat' 파일 강조 (빨간 화살표)]

### 3-2. Windows 보안 경고 — 정상입니다

Windows Defender SmartScreen 이 경고창을 띄울 수 있습니다. 본 도구는 깃허브에 공개된 오픈소스이고 안전합니다.

**'추가 정보' → '실행' 순서로 누르세요.**

[스크린샷 자리: SmartScreen 경고창, '추가 정보' → 두 번째 화면의 '실행' 버튼에 빨간 동그라미]

### 3-3. 환영 화면

검은 PowerShell 창이 열리고 환영 메시지가 나옵니다. **Enter** 키를 누르면 설치가 시작됩니다.

[스크린샷 자리: 환영 화면 — "계속하려면 Enter 를 누르세요" 부분 강조]

### 3-4. OC 키 입력

"이미 OC 키가 있습니까? (Y/N)" 질문에 **Y** 입력 → Enter.

"OC 키를 붙여넣으세요" 에서 **마우스 우클릭** 으로 1단계에서 복사한 키 붙여넣기 → Enter.

[GIF 자리: OC 키 입력 → 화면에 "[OK] OC 키 등록: gil*****" 표시까지 5초]

> PowerShell 에서는 Ctrl+V 가 안 되고 마우스 우클릭이 붙여넣기입니다.

### 3-5. 자동 설치 진행

Python 도구(uv), Claude Desktop, caselaw-mcp 패키지가 자동으로 설치됩니다. 1-5분 정도 걸립니다.

[GIF 자리: 진행 막대가 움직이는 모습 → "[OK]" 메시지가 차례로 뜨는 모습 (10초 발췌)]

### 3-6. 설치 완료

5단계까지 모두 완료되면 "모든 설정이 끝났습니다!" 메시지가 보입니다. Enter 누르면 창이 닫힙니다.

[스크린샷 자리: 5단계 완료 화면, "다음 절차로 사용하세요:" 안내 부분 강조]

## 4단계: Claude Desktop 켜고 첫 사용 (1분)

### 4-1. Claude Desktop 재시작

이미 켜져 있다면 시계 옆 트레이의 Claude 아이콘 우클릭 → **Quit**. 그 후 시작 메뉴에서 다시 실행.

[GIF 자리: 트레이 아이콘 우클릭 → Quit → 시작 메뉴에서 Claude 검색·실행 (8초)]

### 4-2. 도구 등록 확인

채팅창 좌하단의 도구 아이콘을 누르면 **caselaw 서버에 도구 44개** 가 보입니다.

[스크린샷 자리: 도구 목록 펼쳐진 모습, 'caselaw' 부분과 '44 tools' 강조]

### 4-3. ping 테스트

채팅창에 입력:

```
caselaw 로 ping 해줘
```

응답에 **`oc_configured: true`** 가 나오면 성공입니다.

[스크린샷 자리: ping 응답 화면, oc_configured: true 부분 빨간 동그라미]

## 자주 묻는 질문

### Q. 설치 중 winget 이 없다고 나오면?

Windows 10 1809 이전 버전입니다. Microsoft Store 에서 'App Installer' 를 검색해 설치하세요.

[스크린샷 자리: Microsoft Store 의 App Installer 페이지]

### Q. OC 키를 잃어버렸어요.

법제처 사이트에 다시 로그인 → 마이페이지 → API인증키관리 에서 언제든 확인 가능.

### Q. 다른 컴퓨터에 옮기려면?

같은 OC 키로 다른 컴퓨터에서도 설치 가능합니다. 본 가이드를 그대로 따라하시면 됩니다.

### Q. 무료인가요?

전부 무료입니다. 법제처 OC 키, Claude Desktop (개인 사용), 본 도구 모두.
