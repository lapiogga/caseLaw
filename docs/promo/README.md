# 홍보·튜토리얼 자료 (promo)

본 폴더는 비기술자 사용자가 본 MCP 를 쉽게 설치·사용할 수 있도록 돕는 시각·영상 자료의 **대본·가이드·골격** 입니다. 실제 캡처 이미지/영상은 사용자가 본 자료를 참고해 직접 제작합니다.

## 파일 안내

| 파일 | 용도 | 사용자 노력 |
|---|---|---|
| `Vrew_슬라이드쇼_제작_완전가이드.md` | **Vrew 처음 사용자용**. 화면 녹화 없이 11장 캡처 + AI 음성으로 3분 영상 제작 (설치~YouTube 업로드 전체) | 1-1.5시간 |
| `영상_대본_5분.md` | 5분 YouTube/Loom 영상의 시간별 음성·자막·화면 안내 (화면 녹화 영상용) | 화면 녹화 30분 + 편집 30분 |
| `GIF_가이드_골격.md` | README/docs 에 들어갈 GIF·스크린샷 기반 단계별 가이드 골격 | GIF 캡처 1시간 (ScreenToGif 사용) |
| `Vrew_제작_가이드.md` | Vrew 로 화면녹화 + AI 음성 + 자막 자동 합성하는 워크플로 (정통 영상용) | 1-2시간 |

## 작업 순서 추천

1. **GIF 가이드** (빠름, 효과 큼) — 스크린샷 + 짧은 GIF 10개 정도 캡처해 마크다운에 채움
2. **영상 대본** (중간) — 대본 그대로 읽으면서 OBS 로 녹화 → YouTube 업로드
3. **Vrew 영상** (느리지만 높은 품질) — Vrew 의 AI 음성으로 더빙, 다국어 확장 가능

## 각 파일 상세

각 파일을 읽으시고 본인 상황에 맞는 방식 1-2가지를 선택해 진행하시면 됩니다. 셋 다 진행할 필요는 없습니다 — **GIF 가이드 + Vrew 영상** 조합이 가장 효과가 큽니다.
