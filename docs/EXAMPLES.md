## 사용 팁 (변호사용)

- **기본 응답 건수는 20건**. "30건 가져와" 라고 하면 100건까지 자동 페이지네이션.
- **사건번호로 직접 조회**가 안 되면 사건명 일부로 검색 → prec_id 확보 → 본문 호출.
- **인용 형식**으로 정리해 달라고 하면 "대법원 2025. 1. 29. 선고 2025도15970 판결" 형식으로 변환됨.
- **참조조문**은 본문 응답의 `referenced_articles` 필드에 자동 포함.
- **전문(`full_text`)** 은 길어서 토큰을 많이 쓰므로 "요약만" / "판시사항만" 명시 권장.

## 자주 쓰는 코드

| 의미 | 값 |
|---|---|
| 형사 | `case_type="형사"` 또는 `"criminal"` 또는 `"400102"` |
| 민사 | `case_type="민사"` 또는 `"civil"` 또는 `"400101"` |
| 행정 | `case_type="행정"` 또는 `"administrative"` 또는 `"400105"` |
| 대법원 | `court="대법원"` 또는 `"supreme"` |
| 헌재 | `court="헌법재판소"` 또는 `"constitutional"` |
| 사건명만 검색 | `search_scope="title"` |
| 본문만 검색 | `search_scope="body"` |
