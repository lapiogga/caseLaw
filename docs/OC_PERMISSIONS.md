# OC_PERMISSIONS — 법제처 OPEN API 권한 확장 가이드

> Phase 3 도구 중 일부(특별행정심판·중앙부처 1차해석)가 0건만 회수된다면 본 문서가 답입니다.

| 헌재결정례 / 법령해석례 / 행정심판례 | ✅ 정상 (집회 84 / 개인정보 50 / 운전면허 2970) | 동작 중 |
| 위원회 결정문 12종 | ✅ 정상 (공정위 담합 등) | 동작 중 |

| **특별행정심판 4종** | ❌ 0건 (조세·해양·소청·권익특별) | 코드 OK, 권한 외 추정 |
| **중앙부처 1차해석 39종** | ❌ 0건 (법무부·노동부·환경부 등) | 코드 OK, 권한 외 추정 |

→ MCP 코드는 모두 정상. **권한 확장 시 같은 코드가 즉시 동작**합니다.

## 2. 추가 신청 절차

### 2.1 마이페이지 진입

1. https://open.law.go.kr 로그인
2. 우상단 **마이페이지** 클릭
3. 좌측 메뉴 **OPEN API 신청** 또는 직접 https://open.law.go.kr/LSO/openApi/cuAskList.do

### 2.2 신청서 수정 또는 신규 등록

기존 박재우님 신청 (개인, 승인됨)을 **수정**하여 활용 도메인 추가:

1. 신청 목록에서 본인 항목 체크 → **수정** 버튼
2. **활용 목적·신청 데이터** 항목에 다음 도메인을 명시 추가:
   - "특별행정심판례 (조세심판원·해양안전심판원·국민권익위원회·소청심사위원회)"
   - "중앙부처 1차 법령해석 (39개 부처)"
3. 활용 목적 필드: **"개인 변호사·로펌 업무 보조용 MCP 서버 구축, 자연어 검색·인용 자동화"** 같이 구체적으로
4. 저장 → 자동 승인 (단, 활용 목적이 비어 있으면 거절)

### 2.3 승인 후 검증

별도 OC 키 발급 없음 (기존 키 유지). 승인 후 즉시 다음 명령으로 검증:

```powershell
cd C:\Users\User\CaseLaw
uv run python tests\integration\smoke_phase3.py
```

`Test F` (조세심판원), `Test G` (법무부 공탁) 가 0건 → 정상 회수로 변하면 권한 확장 성공.

## 3. 신청서 양식 권장 문구

```
■ 활용 목적
개인 변호사 업무 보조 시스템 (CaseLaw MCP) 구축. 법제처가 제공하는
판례·법령·결정례·해석례·심판례·위원회 결정문·법령용어 데이터를 자연어
인터페이스(Claude Desktop, Cursor, VS Code 등)로 통합 검색하여,
변호사가 사건 준비·판례 인용·법령 조사를 가속화할 수 있도록 지원함.

■ 활용 데이터 (전체)
1. 판례 (목록·본문)
2. 현행법령 시행일 (목록·본문)
3. 헌법재판소 결정례
4. 법제처 법령해석례
5. 행정심판례
6. 위원회 결정문 12종 (개인정보·고용보험·공정거래·국민권익·금융·노동·
   방송미디어통신·산재보상·중앙토지수용·중앙환경분쟁·증권선물·국가인권)
7. 법령용어 사전
8. 특별행정심판례 (조세심판원·해양안전심판원·국민권익위원회·소청심사위원회)
9. 중앙부처 1차 법령해석 (39개 부처)

■ 시스템 형태
오픈소스 MCP 서버. 본인 노트북에서만 실행. 외부 공개 없음.
저장된 응답은 사용자 로컬 SQLite 캐시에만 보관 (TTL 적용).
```

## 4. 자주 묻는 점

| Q | A |
|---|---|
| 개인 신청도 위 도메인 모두 가능? | 가이드상 자동 승인 (활용 목적 충실 시). 단 일부 데이터셋은 별도 심사 가능. |
| 키 1개로 모든 도메인 통합? | 예. OC 1개로 모든 target 호출. 도메인별 별도 키 없음. |
