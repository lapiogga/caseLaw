# CaseLaw — 한국 법률 AI 어시스턴트

> **한국 판례·법령·헌재 결정·행정심판례까지 ChatGPT 같은 AI 채팅창에서 자연어로 검색하고 분석합니다.**
> 변호사·일반인·외국인 누구나, 5분 설치, 영구 무료.

---

## 누구에게 좋습니까

| 대상 | 이렇게 씁니다 |
|---|---|
| **변호사·로펌** | *"음주운전 양형 5건 사건번호와 함께 표로 정리"* → 실제 대법원 판례 5건 자동 회수 |
| **일반인** | *"3년 전 친구한테 5천만원 빌려줬는데 안 갚아요"* → 분쟁 분류·시효·소송비용·무료자원 자동 안내 |
| **외국인** (한국 거주) | 한국어 외 4개 언어 (영어·중국어·베트남어·일본어) 지원. 외국인 전용 무료 상담처도 자동 연결 |

---

## 무엇을 자동으로 해줍니까

### 1️⃣ 변호사 시나리오 — 판례 검색·인용·요약

> *입력*: "도로교통법 위반 음주운전 사건 중 양형이 가장 무거운 5건"
>
> *결과*: 사건번호 · 법원 · 판시사항 · 판결요지가 표로 자동 정리. **인용된 사건번호는 100% 실재.**

### 2️⃣ 일반인 시나리오 — 분쟁 사전진단 (변호사 상담 전 단계)

> *입력*: "횡단보도에서 자전거를 탄 채로 사람과 충돌. 보상 어떻게?"
>
> *결과*: 도로교통법·민법 책임 비율 + 보상 범위 표 + 무료 법률상담 7곳 안내 + 변호사 상담 시 물어볼 질문 10개 자동 작성

### 3️⃣ 외국인 시나리오 — 모국어 분쟁 안내

> *입력*: "I'm a foreign worker. Haven't been paid for 3 months."
>
> *결과*: 영어로 답변 + 외국인종합안내센터 1345·이주민 노동상담 등 외국인 전용 자원 자동 제공.

## 신뢰할 수 있습니까

| 신뢰 요소 | 설명 |
|---|---|
| **공식 데이터** | 법제처 국가법령정보 OPEN API (정부 운영, 191종 데이터) |
| **인용 사건번호** | **100% 실재.** 가짜 판례·할루시네이션 없음. 데이터는 항상 현재 시행 중인 법령·실제 등재된 판례에서만 발췌 |
| **개인정보** | 사용자 입력은 본인 PC 안의 Claude Desktop 에서만 처리. 별도 서버에 저장 안 됨 |
| **라이선스** | MIT 오픈소스. 코드 전체 공개 검증 가능 |

## 지금 시작하기 (5분)

1. **무료 OC 키 발급** — 법제처 사이트에서 5분 회원가입 → 활용신청
2. **설치 패키지 다운로드** — GitHub 에서 7KB ZIP 받아 압축 풀기
3. **`설치하기.bat` 더블클릭** — 화면 안내대로 OC 키 붙여넣기

설치 후 Claude Desktop 켜고 채팅창에 *"caselaw 로 ping해 줘"* 입력하면 끝. 자세한 9단계 시각 가이드는 GitHub 의 `docs/설치_시각가이드.md` 참고.
