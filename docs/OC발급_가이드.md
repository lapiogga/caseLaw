# 법제처 OC 키 발급 가이드 (5분, 무료)

> 컴퓨터에 익숙하지 않으신 분도 5분이면 끝납니다. 화면에 나오는 대로만 따라하세요.

## 왜 필요한가?

CaseLaw MCP 가 한국 판례·법령을 검색할 때 **법제처(국가법령정보센터) 의 OPEN API** 를 사용합니다. 법제처는 누가 사용하는지 확인하기 위해 **OC 키** (사용자 식별자) 를 요구합니다. 무료이고, 본인이 발급받은 키만 본인이 사용합니다.

---

## 발급 절차 (9단계)

### 1단계 — 법제처 OPEN API 사이트 접속

브라우저로 다음 주소 접속:

<https://open.law.go.kr/LSO/openApi/cuAskList.do>

> 자동 설치 스크립트(`설치하기.bat`)를 실행하셨다면 이 페이지가 자동으로 열립니다.

### 2단계 — 우측 상단 "회원가입"

이미 회원이라면 **로그인** 후 **5단계로**.

### 3단계 — 회원가입 양식 작성

- 이메일, 이름, 비밀번호 입력
- **이메일은 평소 사용하시는 것으로 — OC 키가 보통 이메일 ID 의 @ 앞부분과 같습니다.**
  - 예: `gildong@naver.com` → OC 키는 `gildong`

### 4단계 — 이메일 인증

가입한 이메일 받은 편지함에서 인증 메일 클릭.

### 5단계 — 로그인

가입한 이메일·비밀번호로 로그인.

### 6단계 — "활용신청" 메뉴

상단 메뉴에서 **활용신청** 클릭.

### 7단계 — 신청 양식 작성

| 항목 | 입력값 |
|---|---|
| 활용 목적 | "개인 법률 정보 검색" 또는 "AI 보조 도구 사용" |
| 활용 분야 | "기타" 또는 "개인 학습" |
| 사용 기관 | 개인이면 본인 이름 |
| 활용 API | **전체 선택** (또는 최소: 판례, 법령, 헌재결정례, 법령해석례, 행정심판례, 법령용어) |

### 8단계 — 신청 완료

신청 후 **즉시 자동 승인** 되는 경우가 대부분입니다 (개인 신청 기준). 일부 API 는 별도 승인이 필요할 수 있지만, 판례·법령은 즉시 사용 가능합니다.

### 9단계 — OC 키 확인

상단 **마이페이지 → API인증키관리** 또는 **활용현황** 메뉴.

화면에 표시된 **사용자 ID** (영문·숫자 조합) 가 OC 키입니다.

> **예시**: `gildong`, `lawyer123`, `kim_a` 같은 형태. 이메일 전체가 아니라 **앞부분만** 입니다.

복사 (Ctrl+C) 후, 자동 설치 스크립트의 입력 화면에 붙여넣기 (Ctrl+V).

## 자주 묻는 질문

### Q1. 어떤 키를 입력해야 하나요?

화면에서 "사용자 ID" 또는 "OC" 라고 표시된 것. 보통 영문·숫자 조합 5-15자.

이메일 주소 전체(`hong@naver.com`)나 비밀번호가 아닙니다.

### Q2. 발급에 비용이 드나요?

전혀 없습니다. 영구 무료.

### Q3. 키를 잃어버렸어요.

다시 로그인 → 마이페이지 → API인증키관리 에서 언제든 확인 가능.

### Q4. 회사용으로 사용 가능한가요?

개인 사용은 자유. 영리 목적·기관 사용은 활용신청 시 정확한 목적 기재 권장.

### Q5. 한 번 발급받으면 영원히 사용 가능한가요?

네, 별도 갱신 절차 없습니다. 단, 비정상적인 호출(초당 수백 건 등)이 감지되면 차단될 수 있습니다. 본 MCP 는 5 req/sec 로 제한되어 있어 안전합니다.

### Q6. 키를 다른 사람과 공유해도 되나요?

권장하지 않습니다. 사용량이 모두 본인 명의로 집계됩니다.
